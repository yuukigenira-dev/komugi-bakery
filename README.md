# こむぎ日和 | KOMUGI BIYORI BAKERY

架空のベーカリー「こむぎ日和」をテーマに制作したWebサイトです。
店舗コンセプト・店名・ロゴマーク・ビジュアルデザインを考案し、あたたかみのあるベーカリーの世界観を表現しました。

**職業訓練の制作課題｜評価：優（4段階中の最高評価）**

## サイトの内容

- 店舗ロゴとファーストビュー
- おすすめ商品などを紹介する横スクロールバナー
- 店舗からのお知らせ
- 動画・商品紹介・店舗のこだわり
- アクセス情報

## 使用技術

HTML / CSS / JavaScript（jQuery・Slick Slider）

## ファイル構成

```text
index.html
css/
images/
js/
```

## 閲覧方法

`index.html` をブラウザで開くか、GitHub Pagesで公開して閲覧できます。
